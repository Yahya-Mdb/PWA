## Getting Started

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) and npm installed.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Yahya-Mdb/PWA.git
   ```

2. Navigate to the project directory:

   ```bash
   cd PWA
   ```

3. Install the dependencies:

   ```bash
   npm install
   ```

4. Start the Tailwind CSS watcher:

   ```bash
   npm run watch
   ```

5. Open the project in your browser using your preferred local development server.
